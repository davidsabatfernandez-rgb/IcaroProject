# Imágenes de ICARO PROJECT

Las cuatro fotografías activas son reales y se distribuyen bajo licencias gratuitas para uso comercial de Unsplash/Pexels. **No son fotos sin copyright ni se declaran CC0.** [SOURCES.md](./SOURCES.md) conserva autores, fuentes originales, mirrors fijados, IDs, hashes y el alcance de la comprobación.

La portada usa corredores vistos desde arriba y la tarjeta de carrera una silueta en la costa, para evitar primeros planos de atletas o clubes ajenos. Ciclismo y natación ilustran sus disciplinas; no muestran atletas de ICARO, centros propios ni patrocinadores. Una licencia fotográfica no garantiza permisos de imagen, marcas o instalaciones; los mirrors no incluyen esas cesiones y el acceso directo a las páginas originales quedó bloqueado por el proxy.

Para reemplazar una imagen, usa fotografía propia o una fuente que permita expresamente el uso comercial previsto, conserva su prueba de licencia y verifica los permisos de las personas y marcas si resultan necesarias para ese uso. Actualiza `src/config/site.ts`, `site.photographyCredits` y `SOURCES.md` juntos. Mantén los créditos aunque la licencia no los exija. Prefiere WebP/AVIF y originales de al menos 1200 px de ancho para bloques grandes.
